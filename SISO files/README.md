This folder contains channel data from SISO wireless simulations.

The dataset is organized into subfolders based on different transmission scenarios:

- **Ascending Tx 40m Altitude**  
  The transmitter (Tx) ascends vertically during transmission.

- **Moving Rx, Stationary Tx**  
  The receiver (Rx) moves along a defined path while the transmitter remains stationary.

- **No Trajectory**  
  Both the transmitter and receiver are fixed with no movement during the simulation.

Each scenario includes P2m files generated using the Wireless Insite simulation environment.
